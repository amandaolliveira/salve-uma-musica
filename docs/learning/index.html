Learning workspace

Short hands-on lessons for the Salve Uma Música project. Each of the three members follows one track; finishing all three tracks completes the project. Switch language with the buttons at the top right.

How to follow

  1. Do the base lessons your track asks for.
  2. Do your track, in order.
  3. At the end, all three do base lesson 5 (presentation rehearsal) together.

Tracks

  • Base lessons (branch master)
    Docker, MongoDB and RESTHeart, Postman, the Deezer proxy, and the presentation rehearsal.
  • Backend / API track (branch master)
    Before it: base lessons 1 to 4. Read app.js until you can explain it, run the whole Postman collection, and test the project from zero.
  • Database track (branch banco-de-dados)
    Before it: base lessons 1 and 2. From MySQL to MongoDB, the database in Docker, MongoDB Compass, and documenting the model.
  • Frontend track (branch frontend)
    Before it: base lesson 1. The frontend inside nginx, the HTML map, flexbox, grid and the phone layout.

If a track link does not open, that track lives on another branch. Switch with git checkout banco-de-dados or git checkout frontend, then reload this page.

Espaço de aprendizado

Aulas curtas e práticas para o projeto Salve Uma Música. Cada um dos três integrantes segue uma trilha; terminar as três trilhas completa o projeto. Troque o idioma nos botões no canto superior direito.

Como seguir

  1. Faça as aulas base que a sua trilha pede.
  2. Faça a sua trilha, na ordem.
  3. No fim, os três fazem juntos a aula base 5 (ensaio da apresentação).

Trilhas

  • Aulas base (branch master)
    Docker, MongoDB e RESTHeart, Postman, o proxy do Deezer e o ensaio da apresentação.
  • Trilha backend / API (branch master)
    Antes dela: aulas base 1 a 4. Ler o app.js até conseguir explicá-lo, rodar a coleção inteira do Postman e testar o projeto do zero.
  • Trilha banco de dados (branch banco-de-dados)
    Antes dela: aulas base 1 e 2. Do MySQL ao MongoDB, o banco no Docker, o MongoDB Compass e a documentação do modelo.
  • Trilha frontend (branch frontend)
    Antes dela: aula base 1. O frontend dentro do nginx, o mapa do HTML, flexbox, grid e o layout no celular.

Se o link de uma trilha não abrir, ela está em outra branch. Troque com git checkout banco-de-dados ou git checkout frontend e recarregue esta página.
