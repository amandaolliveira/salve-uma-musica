Lesson 1: Run your database with one command

Win: start the containers, see them "running", and know what each command does to your data.

1. What is a container?

A container is an isolated process that carries every file it needs, so it behaves the same on any machine. Unlike a virtual machine it shares the host's kernel, so it is light. (Docker docs) Your project uses three: one for MongoDB (stores documents), one for RESTHeart (turns MongoDB into an HTTP API) and one for nginx (serves the frontend, see lesson 4).

2. What is Compose?

Compose describes several containers, networks and volumes in one YAML file and starts them together. (Docker docs) Your file is docker-compose.yml in the repo root. Three lines matter most:

ports:
  - "8080:8080"          # host port : container port. Left side is YOUR computer.
volumes:
  - dados-mongo:/data/db # named volume mounted where MongoDB writes its data
depends_on:
  - mongodb              # start MongoDB first

3. Try it

Open a terminal in the repo root (where docker-compose.yml is). Docker Desktop must be open.

docker --version
docker compose up -d     # first run downloads the images, be patient
docker compose ps        # all three services should say "running"
docker compose logs -f restheart   # Ctrl+C to leave the logs

Then open http://localhost:8080 in your browser. A login prompt (or JSON) means RESTHeart is answering. Use admin / secret.

Stuck? Copy the exact error message before asking for help. Port 8080 busy? Change the left number only (e.g. "8081:8080").

4. Check yourself

Aula 1: Rode seu banco de dados com um comando

Objetivo: subir os contêineres, vê-los como "running" e saber o que cada comando faz com seus dados.

1. O que é um contêiner?

Um contêiner é um processo isolado que leva consigo todos os arquivos de que precisa, então se comporta igual em qualquer máquina. Diferente de uma máquina virtual, ele usa o kernel do computador hospedeiro, por isso é leve. (Documentação do Docker, em inglês) Seu projeto usa três: um para o MongoDB (guarda os documentos), um para o RESTHeart (transforma o MongoDB em uma API HTTP) e um para o nginx (serve o frontend, ver aula 4).

2. O que é o Compose?

O Compose descreve vários contêineres, redes e volumes em um único arquivo YAML e os inicia juntos. (Documentação do Docker, em inglês) Seu arquivo é o docker-compose.yml, na raiz do repositório. Três linhas importam mais:

ports:
  - "8080:8080"          # porta do host : porta do contêiner. O lado esquerdo é o SEU computador.
volumes:
  - dados-mongo:/data/db # volume nomeado montado onde o MongoDB grava seus dados
depends_on:
  - mongodb              # inicie o MongoDB primeiro

3. Experimente

Abra um terminal na raiz do repositório (onde está o docker-compose.yml). O Docker Desktop precisa estar aberto.

docker --version
docker compose up -d     # na primeira vez baixa as imagens, tenha paciência
docker compose ps        # os três serviços devem aparecer como "running"
docker compose logs -f restheart   # Ctrl+C para sair dos logs

Depois abra http://localhost:8080 no navegador. Um pedido de login (ou um JSON) significa que o RESTHeart está respondendo. Use admin / secret.

Travou? Copie a mensagem de erro exata antes de pedir ajuda. Porta 8080 ocupada? Troque só o número da esquerda (por exemplo, "8081:8080").
