Backend 3: From zero to a game

Win: start the project from an empty database, exactly like the professor will (docker compose up -d and nothing else), and tick every requirement on the way. Do it once now, and again after the branches are merged.

1. The checklist

Run from the repo root. Tick each line only when you see the expected result.

#DoExpect
1docker compose down -vContainers and the dados-mongo volume removed (the database is now empty).
2docker compose up -d, then docker compose psmongodb, restheart and frontend running.
3Open http://localhost:3000 with F12 → Network openGET musica?pagesize=1 404, then PUT musica 201 (same for artista). The list says the database is empty.
4Importar: pick a genre, click ImportarGreen message "100 música(s) nova(s), 0 já estava(m)". The dashboard shows 100 songs.
5Import the same genre again"0 música(s) nova(s), 100 já estava(m)". Nothing duplicated.
6Play an 8-song gameThe winner appears with 1 win; ranking and charts change by themselves.
7Send the form empty, then add a songThe list of errors first; then a 201 and the song in the list.
8Edit that song, then delete itGET by id + PUT (200); DELETE (204) after the confirmation.
9Search and filtersTyping part of an artist filters the list; the genre and origin filters work.
10Postman: run the collection (lesson 2)All tests pass.
11docker compose down, then up -dThe songs and wins are still there (named volume).

2. If something goes wrong

SymptomCause and fix
Bind for 0.0.0.0:27017 failed: port is already allocatedAnother container or MongoDB uses that port (common if you have another project running). docker ps shows who; stop it with docker stop <name>. The 27017 port is only for Compass, so you can also change its left number.
Same error for 8080 or 3000Change only the left number. For 8080, also change API at the top of frontend/app.js.
"Erro: Failed to fetch (o banco está rodando?...)"RESTHeart was still starting. Wait 10 seconds, reload.
"Erro ao carregar gêneros do Deezer"No internet, or the page was opened from disk instead of localhost:3000 (no proxy).
Import stops halfway with an HTTP errorRead the status in the message. Run it again: songs already saved count as 409 and are skipped.

Objetivo: subir o projeto com o banco vazio, do jeito que o professor vai fazer (docker compose up -d e mais nada), e marcar cada requisito no caminho. Faça uma vez agora, e de novo depois que as branches forem mescladas.

Rode na raiz do repositório. Marque cada linha só quando vir o resultado esperado.

2. Se algo der errado

SintomaCausa e solução
Bind for 0.0.0.0:27017 failed: port is already allocatedOutro contêiner ou MongoDB usa essa porta (comum se você tem outro projeto rodando). O docker ps mostra quem; pare com docker stop <nome>. A porta 27017 só serve para o Compass, então você também pode trocar o número da esquerda.
O mesmo erro para 8080 ou 3000Troque só o número da esquerda. Para a 8080, troque também a API no topo do frontend/app.js.
"Erro: Failed to fetch (o banco está rodando?...)"O RESTHeart ainda estava subindo. Espere 10 segundos e recarregue.
"Erro ao carregar gêneros do Deezer"Sem internet, ou a página foi aberta do disco em vez de localhost:3000 (sem proxy).
A importação para no meio com um erro HTTPLeia o status na mensagem. Rode de novo: as músicas já salvas dão 409 e são puladas.
