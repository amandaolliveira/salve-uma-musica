# One track per role

The group has three roles: backend/API, database and frontend. Shared lessons moved to `base/`; each role got its own folder (`trilha-backend/`, `trilha-banco-de-dados/`, `trilha-frontend/`) and its own lesson list (`trilha.js`), so the branches never edit the same file. The backend code was already written, so its track is about explaining and testing it; the other two tracks end with each member's own commits. The colleagues cannot ask for help while studying, so every lesson carries exact commands, expected results, troubleshooting and answer keys.
