# Moved to this repo: numeric ids instead of text

The lessons came from another repo that stored Deezer ids as text. This repo's model (`docs/estrutura_banco.md`) uses numbers, so lessons 2 and 3 now teach `?id_type=NUMBER` instead, and the "unknowns" from the old game design were dropped. Lesson 4 (proxy and CORS) was added because the frontend is now built.
