Database 4: Seeing the data in MongoDB Compass

Win: open the real database in Compass (the MongoDB equivalent of MySQL Workbench), find the two collections, run filters and sorts, and write down the numbers you will use in lesson 5. Needs lesson 3 done and at least one genre imported.

1. Install and connect

  1. Download MongoDB Compass from mongodb.com/try/download/compass and install it.
  2. Make sure the project is running: docker compose ps.
  3. In Compass, create a new connection with the URI mongodb://localhost:27017 and click Connect. (Compass docs: connect)

No user or password: this MongoDB has no login because it only runs on your computer. The admin / secret login belongs to RESTHeart, not to MongoDB.

2. What you will see

On the left, four databases: admin, config, local (MongoDB's own) and restheart (ours). Open restheart:

CollectionWhat it is
musicaThe songs. Ours.
artistaThe artists, referenced by id_artista. Ours.
users, acl, _propertiesRESTHeart's own (its login and permissions). Do not change or delete them: the app would stop working.

Open musica. The Documents tab shows the total at the top (for example "1 – 20 of 100"). Open one document and look at the types (switch to the table view or hover a value):

  • _id: Int32 or Int64 (big Deezer ids need 64 bits). A song added by hand shows an ObjectId instead.
  • artista: Object, with id_artista and nome_artista inside: the embedded part.
  • criado_em: String with a date in ISO format (2026-11-05T22:40:00.000Z).
  • _etag: an ObjectId that RESTHeart adds to mark the document's version. The app ignores it.

3. Filters and sorting

(Compass docs: query your data) Type in the Filter bar and click Find. Under Options there are Sort and Limit.

Filter                                  SQL equivalent
{ genero: "Rock" }                      WHERE genero = 'Rock'
{ vitorias: { $gt: 0 } }                WHERE vitorias > 0
{ adicionado_manualmente: true }        WHERE adicionado_manualmente = 1
{ "artista.nome_artista": "Queen" }     WHERE nome_artista = 'Queen' (no JOIN!)

Sort { vitorias: -1 } and Limit 10      ORDER BY vitorias DESC LIMIT 10

The fourth filter reaches inside the embedded object with a dot. That is the practical gain of embedding.

4. Do it and write it down

  1. Play one or two games in the app (localhost:3000), then in Compass run { vitorias: { $gt: 0 } }: the winners appear. Click the refresh button if the list is old.
  2. Note for lesson 5: the date, the total of musica, the total of artista, how many genres you imported, and one filter you ran with its result count.

Compass can edit and delete documents. Do not use it for that: changes go through the app or Postman, which is what the assignment evaluates.

Answer key: what a normal result looks like
  • One genre imported: musica has about 100 documents (up to 100 per genre; songs already present are skipped).
  • artista has fewer documents than musica, because one artist can have several songs in the chart.
  • { genero: "Rock" } returns the songs of that import; another genre's songs do not appear.
  • After 2 games, { vitorias: { $gt: 0 } } returns 1 or 2 documents (2 if two different songs won).

5. If something goes wrong

SymptomWhat to do
connect ECONNREFUSED 127.0.0.1:27017Containers are not running (docker compose up -d), or you changed the port in lesson 3: use the new one in the URI.
No restheart databaseNothing was created yet. Open localhost:3000 once and import a genre, then refresh Compass.
Numbers do not match the appClick Compass's refresh button; it does not update by itself.

Banco 4: Vendo os dados no MongoDB Compass

Objetivo: abrir o banco de verdade no Compass (o equivalente do MySQL Workbench para o MongoDB), achar as duas coleções, rodar filtros e ordenações, e anotar os números que você vai usar na aula 5. Precisa da aula 3 concluída e de pelo menos um gênero importado.

1. Instale e conecte

  1. Baixe o MongoDB Compass em mongodb.com/try/download/compass e instale.
  2. Confira se o projeto está rodando: docker compose ps.
  3. No Compass, crie uma conexão nova com a URI mongodb://localhost:27017 e clique em Connect. (Documentação do Compass: conectar, em inglês)

Sem usuário nem senha: este MongoDB não tem login porque só roda no seu computador. O login admin / secret é do RESTHeart, não do MongoDB.

2. O que você vai ver

À esquerda, quatro bancos: admin, config, local (do próprio MongoDB) e restheart (o nosso). Abra o restheart:

ColeçãoO que é
musicaAs músicas. Nossa.
artistaOs artistas, referenciados pelo id_artista. Nossa.
users, acl, _propertiesDo próprio RESTHeart (login e permissões dele). Não altere nem apague: o app pararia de funcionar.

Abra a musica. A aba Documents mostra o total no topo (por exemplo "1 – 20 of 100"). Abra um documento e veja os tipos (troque para a visão de tabela ou passe o mouse sobre um valor):

  • _id: Int32 ou Int64 (ids grandes do Deezer precisam de 64 bits). Uma música adicionada à mão mostra um ObjectId.
  • artista: Object, com id_artista e nome_artista dentro: a parte embutida.
  • criado_em: String com uma data no formato ISO (2026-11-05T22:40:00.000Z).
  • _etag: um ObjectId que o RESTHeart coloca para marcar a versão do documento. O app ignora.

3. Filtros e ordenação

(Documentação do Compass: consultar dados, em inglês) Digite na barra Filter e clique em Find. Em Options ficam o Sort e o Limit.

Filtro                                  Equivalente em SQL
{ genero: "Rock" }                      WHERE genero = 'Rock'
{ vitorias: { $gt: 0 } }                WHERE vitorias > 0
{ adicionado_manualmente: true }        WHERE adicionado_manualmente = 1
{ "artista.nome_artista": "Queen" }     WHERE nome_artista = 'Queen' (sem JOIN!)

Sort { vitorias: -1 } e Limit 10        ORDER BY vitorias DESC LIMIT 10

O quarto filtro entra no objeto embutido com um ponto. Esse é o ganho prático de embutir.

4. Faça e anote

  1. Jogue uma ou duas partidas no app (localhost:3000), depois rode no Compass { vitorias: { $gt: 0 } }: as vencedoras aparecem. Clique no botão de atualizar se a lista estiver velha.
  2. Anote para a aula 5: a data, o total da musica, o total da artista, quantos gêneros você importou, e um filtro que você rodou com a quantidade de resultados.

O Compass consegue editar e apagar documentos. Não use para isso: as alterações passam pelo app ou pelo Postman, que é o que o trabalho avalia.

Gabarito: como é um resultado normal
  • Um gênero importado: a musica tem uns 100 documentos (até 100 por gênero; as que já existiam são puladas).
  • A artista tem menos documentos que a musica, porque um artista pode ter várias músicas no chart.
  • { genero: "Rock" } devolve as músicas daquela importação; as de outro gênero não aparecem.
  • Depois de 2 partidas, { vitorias: { $gt: 0 } } devolve 1 ou 2 documentos (2 se duas músicas diferentes venceram).

5. Se algo der errado

SintomaO que fazer
connect ECONNREFUSED 127.0.0.1:27017Os contêineres não estão rodando (docker compose up -d), ou você trocou a porta na aula 3: use a nova na URI.
Não aparece o banco restheartNada foi criado ainda. Abra localhost:3000 uma vez e importe um gênero, depois atualize o Compass.
Os números não batem com o appClique no botão de atualizar do Compass; ele não atualiza sozinho.
