Docker Compose cheat sheet

Run from the folder containing docker-compose.yml. Source: Docker docs.

docker compose up -d              start everything in the background
docker compose ps                 list services and their state
docker compose logs -f restheart  follow one service's logs (Ctrl+C exits)
docker compose down               stop and remove containers, KEEP volumes
docker compose down -v            also DELETE named volumes (data is lost)

Glossary

Container
Isolated process with everything it needs to run.
Service
One entry under services: (mongodb, restheart, frontend).
Port mapping
HOST:CONTAINER, left side is your computer.
Named volume
Storage managed by Docker that outlives containers (dados-mongo).

Guia rápido do Docker Compose

Execute na pasta que contém o docker-compose.yml. Fonte: documentação do Docker (em inglês).

docker compose up -d              inicia tudo em segundo plano
docker compose ps                 lista os serviços e o estado de cada um
docker compose logs -f restheart  acompanha os logs de um serviço (Ctrl+C sai)
docker compose down               para e remove os contêineres, MANTÉM os volumes
docker compose down -v            também APAGA os volumes nomeados (os dados se perdem)

Glossário

Contêiner
Processo isolado com tudo de que precisa para rodar.
Serviço
Cada entrada em services: (mongodb, restheart, frontend).
Mapeamento de porta
HOST:CONTÊINER, o lado esquerdo é o seu computador.
Volume nomeado
Armazenamento gerenciado pelo Docker que dura mais que os contêineres (dados-mongo).
