Frontend track

For the member who knows basic HTML and CSS. You will learn how nginx serves the page from Docker, which parts of the HTML the app depends on, and write the whole style.css with flexbox, grid and a phone layout. Before it: base lesson 1. Branch: frontend.

Trilha frontend

Para quem conhece o básico de HTML e CSS. Você vai aprender como o nginx serve a página pelo Docker, de quais partes do HTML o app depende, e escrever o style.css inteiro com flexbox, grid e layout de celular. Antes dela: aula base 1. Branch: frontend.
