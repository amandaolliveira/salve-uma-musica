Frontend 3: The HTML map

Win: know what in frontend/index.html you can change freely and what would break the app, then write the base of style.css (colors, fonts, sections, buttons) and make your first commit.

1. How app.js finds things

app.js finds elements by id, for example document.getElementById('lista-musicas'). If you rename or remove one of these ids, that part of the page stops working (and the browser console, F12, shows an error). Never rename these ids:

Partids used by app.js
Messagesmensagem
Gameform-jogo, jogo-tamanho, jogo-genero, confronto, confronto-fase, confronto-progresso, jogo-abandonar, vencedor, vencedor-capa, vencedor-titulo, vencedor-artista, vencedor-vitorias, jogo-novo
Dashboardindicadores, grafico-ranking, grafico-generos, ranking, tabela-generos
Songsbusca, filtro-genero, filtro-origem, contagem, lista-musicas
Formform-titulo, form-musica, lista-generos, form-erros, form-enviar, form-cancelar
Importform-importar, importar-genero

Also keep:

  • The two <button class="opcao" data-lado="0|1"> inside #confronto, each with an <img>, a .opcao-titulo and a .opcao-artista inside.
  • The name of the form fields (titulo, nome_artista, genero, duracao, url_capa).
  • The <tbody> of #tabela-generos.

2. Elements that app.js creates

Some elements do not exist in the HTML: app.js builds them. You cannot add classes to them in index.html; style them with the classes they already have:

#lista-musicas
  li.musica
    img.capa
    div.musica-info
      strong.musica-titulo
      span.musica-artista
      span.musica-detalhes
    div.musica-acoes
      button.botao-editar  button.botao-zerar  button.botao-excluir
  li.vazio                (when the list is empty)

#indicadores
  div.indicador
    span.indicador-valor
    span.indicador-rotulo

#mensagem   gets class="mensagem carregando", "mensagem sucesso" or "mensagem erro"

app.js replaces the whole class of #mensagem, so a class you add to it in the HTML is lost. Style it with .mensagem.erro, .mensagem.sucesso and so on.

3. What you are free to do

  • Add classes to any element in index.html.
  • Wrap elements in new <div>s to help the layout.
  • Change texts, headings and the order of the sections.

The HTML already has a class on almost every block (.cabecalho, .menu, .secao, .filtros, .confronto-opcoes, .form-musica, .graficos...). The answer keys in this track only use those.

4. The hidden trap

The game screen, the winner box and the messages are shown and hidden by app.js with the hidden attribute (MDN: hidden). The browser hides it with a very weak rule, so if you write .confronto { display: flex; }, your rule wins and the element never hides again. The first line of your CSS fixes that:

[hidden] { display: none !important; }

5. CSS variables

Write your colors once, at the top, and reuse them (MDN: custom properties):

:root { --destaque: #6c3df4; }
button { background: var(--destaque); }

Changing the theme later is changing one line.

6. Your first CSS

Open frontend/style.css (it is empty) and write, in this order. Reload (Ctrl+F5) after each step and look:

  1. The [hidden] rule.
  2. A :root with your color variables: page background, card background, text, soft text, highlight, text on highlight, border, success, error, and a border radius.
  3. * { box-sizing: border-box; }: width and padding add up the way you expect.
  4. body: no margin, a font, the background and text colors.
  5. main: maximum width about 1100px, centered (margin: 0 auto), with 16px of side padding.
  6. .secao: each section as a white card with padding, border and rounded corners, with space between them.
  7. button, input and select: same font as the page, padding, rounded corners; buttons with the highlight color.

Pick your own colors. The key below is one possible result.

Frontend 3: O mapa do HTML

Objetivo: saber o que no frontend/index.html você pode mudar à vontade e o que quebraria o app, depois escrever a base do style.css (cores, fontes, seções, botões) e fazer o seu primeiro commit.

1. Como o app.js acha as coisas

O app.js acha os elementos pelo id, por exemplo document.getElementById('lista-musicas'). Se você renomear ou remover um desses ids, aquela parte da página para de funcionar (e o console do navegador, F12, mostra um erro). Nunca renomeie estes ids:

3. O que você pode fazer à vontade

  • Colocar classes em qualquer elemento do index.html.
  • Envolver elementos em <div>s novas para ajudar no layout.
  • Mudar textos, títulos e a ordem das seções.

O HTML já tem uma classe em quase todo bloco (.cabecalho, .menu, .secao, .filtros, .confronto-opcoes, .form-musica, .graficos...). Os gabaritos desta trilha só usam essas.

4. A armadilha do hidden

A tela do jogo, a caixa da vencedora e as mensagens são mostradas e escondidas pelo app.js com o atributo hidden (MDN: hidden, em inglês). O navegador esconde com uma regra muito fraca, então se você escrever .confronto { display: flex; }, a sua regra ganha e o elemento nunca mais some. A primeira linha do seu CSS resolve isso:

[hidden] { display: none !important; }

5. Variáveis do CSS

Escreva as suas cores uma vez, no topo, e reutilize (MDN: propriedades personalizadas):

:root { --destaque: #6c3df4; }
button { background: var(--destaque); }

Trocar o tema depois é trocar uma linha.

6. Seu primeiro CSS

Abra o frontend/style.css (ele está vazio) e escreva, nesta ordem. Recarregue (Ctrl+F5) depois de cada passo e olhe:

  1. A regra do [hidden].
  2. Um :root com as variáveis de cor: fundo da página, fundo dos cartões, texto, texto suave, destaque, texto sobre o destaque, borda, sucesso, erro, e um raio de borda.
  3. * { box-sizing: border-box; }: largura e padding somam do jeito que você espera.
  4. body: sem margem, uma fonte, as cores de fundo e de texto.
  5. main: largura máxima de uns 1100px, centralizado (margin: 0 auto), com 16px de padding nas laterais.
  6. .secao: cada seção como um cartão branco com padding, borda e cantos arredondados, com espaço entre elas.
  7. button, input e select: mesma fonte da página, padding, cantos arredondados; botões com a cor de destaque.

Escolha as suas cores. O gabarito abaixo é um resultado possível.
