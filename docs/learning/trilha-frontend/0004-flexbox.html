Frontend 4: Flexbox

Win: lay out the header, the messages, the forms, the two game options and the song cards with flexbox. Needs lesson 3 (your base CSS) and songs imported.

1. Flexbox in five properties

display: flex goes on the parent; its direct children line up in a row (MDN: Flexbox).

PropertyOnWhat it does
flex-direction: columnparentchildren stacked instead of in a row
justify-contentparentspreads children along the row: center, space-between...
align-itemsparentaligns children across the row: center, flex-end...
gapparentspace between children (no margins needed)
flex-wrap: wrapparentchildren go to the next line when they do not fit
flex: 1childthis child grows to fill the free space
flex-basis: 100%childthis child takes a whole line

Example: title on the left, menu on the right:

.cabecalho { display: flex; justify-content: space-between; align-items: center; }

Tip: F12, click an element with display: flex; DevTools shows a small flex badge that draws the layout on the page.

Frontend 4: Flexbox

Objetivo: montar o cabeçalho, as mensagens, os formulários, as duas opções do jogo e os cartões das músicas com flexbox. Precisa da aula 3 (o seu CSS base) e de músicas importadas.

1. Flexbox em cinco propriedades

O display: flex vai no pai; os filhos diretos dele se alinham em uma linha (MDN: Flexbox).

PropriedadeEmO que faz
flex-direction: columnpaifilhos empilhados em vez de lado a lado
justify-contentpaidistribui os filhos ao longo da linha: center, space-between...
align-itemspaialinha os filhos no outro sentido: center, flex-end...
gappaiespaço entre os filhos (sem precisar de margem)
flex-wrap: wrappaios filhos descem para a próxima linha quando não cabem
flex: 1filhoesse filho cresce para ocupar o espaço livre
flex-basis: 100%filhoesse filho ocupa uma linha inteira

Exemplo: título à esquerda, menu à direita:

.cabecalho { display: flex; justify-content: space-between; align-items: center; }

Dica: F12, clique em um elemento com display: flex; o DevTools mostra um selo flex que desenha o layout na página.
